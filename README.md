# MINDSET X

موقع عربي لتطوير الذات والتركيز والانضباط، مع مهام يومية وأهداف ومساعد ذكاء اصطناعي.

## تشغيل محلياً
يتطلب Node.js 18 أو أحدث.

```bash
npm start
```
ثم افتح `http://localhost:3000`.

## تفعيل المساعد الذكي
أضف متغيري البيئة في إعدادات الاستضافة:
- `OPENAI_API_KEY`: مفتاح API الخاص بك.
- `OPENAI_MODEL`: اختياري؛ الافتراضي `gpt-4.1-mini`.

لا تضع مفتاح API في `public/index.html` أو أي ملف يصل إلى المتصفح.

## النشر على الإنترنت
يمكن نشر المشروع على Render أو Railway أو أي استضافة تدعم تطبيقات Node.js:
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. أنشئ خدمة Web Service جديدة واربطها بالمستودع.
3. اجعل أمر التشغيل `npm start`.
4. أضف `OPENAI_API_KEY` في Environment Variables لتفعيل المساعد.
5. انشر الخدمة وافتح الرابط الذي تمنحك إياه الاستضافة.

## ملاحظات
- المهام والأهداف تُحفظ محلياً في متصفح الجهاز باستخدام localStorage، ولا تتم مزامنتها بين الأجهزة.
- هذا الإصدار لا يحتوي على تسجيل حسابات أو قاعدة بيانات سحابية بعد.
- استخدام واجهة OpenAI API قد يترتب عليه رسوم منفصلة وفق حسابك واستهلاكك.
